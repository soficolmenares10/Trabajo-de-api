# Mini Portal de Colombia

## Descripción
Mini Portal de Colombia es una aplicación web desarrollada con HTML, CSS y JavaScript que consume datos en tiempo real desde la API pública de Colombia.

El portal permite explorar información general del país, conocer algunos presidentes de Colombia y descubrir lugares turísticos importantes mediante contenido dinámico cargado directamente en el navegador.

## Objetivo del proyecto
Desarrollar un portal informativo utilizando consumo de APIs con Fetch y manipulación dinámica del DOM.

## Tecnologías usadas
- HTML5
- CSS3
- JavaScript
- Fetch API
- API Colombia

## API utilizada
https://api-colombia.com/

## Páginas del portal

### 1. Colombia en Datos
Muestra información general del país:
- Nombre
- Capital
- Población
- Superficie
- Moneda
- Idioma
- Bandera

### 2. Presidentes de Colombia
Muestra una lista de presidentes ordenados cronológicamente:
- Nombre
- Periodo presidencial
- Partido político
- Imagen

### 3. Guía Turística
Muestra lugares turísticos destacados:
- Nombre
- Ciudad
- Descripción
- Imagen

## Funcionalidades
- Consumo de API mediante Fetch
- Manipulación dinámica del DOM
- Navegación entre páginas
- Mensajes de carga
- Manejo de errores con catch
- Diseño responsive y visual atractivo
